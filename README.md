# Praashant Verma - Professional Portfolio

A dynamic and interactive professional portfolio website showcasing 12+ years of project management expertise with cutting-edge web technologies and engaging user experiences.

## 🌟 Features

- **Modern Design**: Dark theme with blue/purple gradients inspired by Apex template
- **Interactive Animations**: Scroll-triggered animations and 3D floating icons
- **Animated Background**: Large PM tool icons (Jira, Asana, Trello, Slack) with parallax scrolling
- **Responsive Layout**: Fully responsive design that works on all devices
- **Professional Content**: Real resume data and downloadable PDF
- **Smooth Navigation**: Fixed header with smooth scrolling to sections

## 🛠️ Technology Stack

- **Frontend**: React.js with TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React & Custom SVG icons
- **Build Tool**: Vite
- **Deployment**: Netlify

## 🎨 Design Features

- **Hero Section**: Professional introduction with profile picture and call-to-action
- **Experience Timeline**: 12+ years of project management experience
- **Skills Showcase**: Animated progress bars and technology icons
- **Projects Portfolio**: Key achievements and project highlights
- **Education & Certifications**: Academic background and professional certifications
- **Contact Section**: Direct links to LinkedIn, email, and phone

## 🚀 Getting Started

### Prerequisites
- Node.js (version 18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone [your-repo-url]

# Install dependencies
npm install

# Start development server
npm run dev
```

### Building for Production
```bash
# Build the project
npm run build

# Preview the build
npm run preview
```
